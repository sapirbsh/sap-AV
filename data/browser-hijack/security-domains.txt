# sap-AV browser-hijack domain list (ROADMAP E6).
#
# Used two ways:
#  - the browser-hijack rules judge hosts-file entries for these domains (SecurityDomainList / BrowserHijackRules);
#  - the hosts collector keeps entries for these domains past its entry cap (HostsNameFilter.DefaultSecurityDomains).
#
# Format: "[group]" starts a group; every other line is one domain suffix, which matches the domain itself and every
# subdomain ("microsoft.com" matches "www.microsoft.com", never "evilmicrosoft.com" or "microsoft.com.evil.net").
# Lower-case ASCII only (write IDN domains in punycode), no leading or trailing dot. '#' starts a comment.
# Caps (HostsNameFilter): at most 128 suffixes and 8192 characters in total.
#
# Groups (a name in more than one group takes the most severe):
#  defender  Windows Update, Microsoft Defender, SmartScreen. Redirect or block -> Malicious (block = Defender tampering).
#  security  Antivirus vendors and online scanners.            Redirect or block -> Malicious.
#  accounts  Major sign-in, banking, payment and crypto sites.  Redirect -> Malicious. Block -> nothing (privacy and
#            social-media block lists do that on purpose).
